# LIB_EMITTERS

Energy weapons drawn as vector lines made of math: lightning, fire, plasma, photon, sound and
heat, as **element x form** (fire + ball = fire ball). A library, an editor stack to tune the
powers around two stick figures, and a cute food-fight duel for PROMPT & GLAZE.

Status (22 Nov 2026): plan only, nothing built yet. Read `PLAN.md`.
